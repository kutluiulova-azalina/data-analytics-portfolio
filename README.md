# Анализ рекламных кампаний и продаж Wildberries (сен–окт 2025)

Оценка эффективности рекламы и продаж на Wildberries: расчёт ДРР, ABC-анализ, поиск убыточных товаров и анализ выручки по категориям.

Ключевой вывод: реклама убыточна — 4 из 5 товаров имеют ДРР > 200%; 2 категории из 8 дают ~87% выручки.
