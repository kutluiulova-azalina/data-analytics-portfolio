## 🔗 Цель проекта 

Оценить эффективность рекламных кампаний на маркетплейсе Wildberries за сентябрь–октябрь 2025 года: 

- рассчитать долю рекламных расходов (ДРР) по каждому товару; 

- выявить убыточные и прибыльные товары; 

- проанализировать структуру выручки по категориям; 

- подготовить рекомендации для маркетингового отдела.

## 🔗 Рекомендации 

1. **Пересмотреть ставки в рекламных кампаниях** для товаров с ДРР > 200% — они убыточны. 

2. **Увеличить закупки по товарам-лидерам** (Губка одноразовая, Тапки спанбонд, Тапки махровые). 

3. **Провести аудит категорий** с нулевой прибылью — возможно, стоит вывести их из ассортимента. 

4. **Сконцентрировать рекламный бюджет** на 7 товарах категории A (80% выручки). 

5. **Стимулировать разнообразие покупок** — большинство товаров не покупают вообще.
