# Анализ вакансий аналитиков данных и системных аналитиков (hh.ru, май–июнь 2024)

SQL-анализ рынка вакансий для аналитиков данных и системных аналитиков на основе данных hh.ru за май–июнь 2024: зарплаты, регионы, работодатели, грейды, условия работы и востребованные навыки.

Ключевой вывод: рынок централизован вокруг Москвы и крупных корпораций (Сбер, Wildberries, Ozon); спрос смещён в сторону специалистов с опытом 1–3 года.

## 🎯 Цель
Изучить рынок труда для аналитиков: какие компании ищут специалистов, сколько платят, какие навыки требуют.

## 📊 Данные
Таблица `public.parcing_table` с вакансиями hh.ru за май–июнь 2024.
⚠️ Сырые данные не публикуются — только SQL-запросы и агрегированные результаты.

## 🛠️ Инструменты
- SQL (PostgreSQL)
- DBeaver

## 🔍 Ход анализа
1. Диапазон зарплат (средние, минимумы, максимумы)
2. Регионы и компании-лидеры по числу вакансий
3. Типы занятости и графики работы
4. Распределение грейдов (Junior, Middle, Senior)
5. Работодатели, зарплаты и условия труда для аналитиков
6. Востребованные hard и soft skills по грейдам

## 📈 Результаты
- Основной диапазон зарплат: 50 000 – 200 000 ₽, средняя ~131 700 ₽
- Москва — 1 247 вакансий, Санкт-Петербург — 181, Екатеринбург — 51
- Топ-работодатели: СБЕР (243), Wildberries (43), Ozon (34), ВТБ (28), Т1 (26)
- Полная занятость — ~98% вакансий; полный день — ~80%
- Junior+ (1–3 года опыта) — 1 091 вакансия (75%)
- Ключевые навыки: SQL, Python, визуализация данных, коммуникация, работа с документацией

## 📌 Вывод
Рынок аналитиков централизован вокруг Москвы и крупных корпораций. Спрос смещён в сторону специалистов с опытом 1–3 года. Работодатели ожидают владения SQL, Python и навыков визуализации, а также развитых soft skills.
